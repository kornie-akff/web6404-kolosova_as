# Лабораторная работа №2

**Тема:** Разработка многостраничного web-сайта «CITRUS — Cover Dance Team»

## О проекте

Сайт посвящён k-pop cover dance команде **CITRUS CDT**: состав участниц, реализованные проекты (кавер-выступления) и достижения на конкурсах и фестивалях

**Технологии:** HTML, CSS

## Структура сайта

`index.html` Главная страница — описание команды, галерея групповых фото
`members.html` Участницы — карточки с фото и личная информация
`projects.html` Проекты — карточки с фото тизерами проектов, ссылки на видео на YouTube
`achievements.html` Достижения — таблица наград
`css/style.css` Единый файл стилей для всех страниц
