# Лабораторная работа №3

**Тема:** Изучение основ JavaScript

## О проекте

Реализация набора функций на чистом JavaScript: работа с числами, массивами, замыканиями, рекурсией и глубоким сравнением объектов. Проверка решений автоматическая

**Технологии:** JavaScript, Node.js

## Структура проекта

`lab3/src/core.js` — реализации 10 функций
`lab3/src/core.spec.js` — тесты

## Реализованные функции

`isInteger(n)` — проверяет, целое ли число
`even()` — возвращает массив чётных чисел от 2 до 20
`sumTo(n)` — сумма чисел от 1 до n (через цикл)
`recSumTo(n)` — сумма чисел от 1 до n (через рекурсию)
`factorial(n)` — факториал числа n
`isBinary(n)` — проверяет, является ли число степенью двойки
`fibonacci(n)` — возвращает n-е число Фибоначчи
`getOperationFn(initialValue, operatorFn)` — возвращает функцию-калькулятор с памятью (замыкание)
`sequence(start, step)` — генератор арифметической последовательности (замыкание)
`deepEqual(a, b)` — глубокое сравнение двух значений по содержанию
