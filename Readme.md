# Лабораторная работа №4

**Тема:** Изучение современного CSS и основ ООП на JavaScript

## О проекте

Модернизация сайта **CITRUS CDT** из лабораторной №2: вёрстка переведена на Flexbox и Grid, все цвета вынесены в CSS-переменные, добавлена CSS-анимация, реализована страница с формой обратной связи и класс на JavaScript для обработки введённых данных. Вёрстка выполнена по методологии БЭМ

**Технологии:** HTML, CSS (Flexbox, Grid, CSS-переменные, анимации), JavaScript (классы, ООП)

## Структура проекта

`lab4/index.html` — Главная страница
`lab4/members.html` — Участницы (вёрстка через Flexbox)
`lab4/projects.html` — Проекты (вёрстка через Grid)
`lab4/achievements.html` — Достижения (таблица наград)
`lab4/contact.html` — Форма обратной связи
`lab4/css/style.css` — Единый файл стилей, все цвета заданы через переменные в `:root`
`lab4/js/form.js` — Класс `ContactRequest` и обработка отправки формы

## Реализовано

- **Flexbox** — страница участниц (`members.html`): карточки выстроены в колонку, чётные карточки развёрнуты через `flex-direction: row-reverse`
- **Grid** — страница проектов (`projects.html`): карточки построены на `grid-template-columns`, чётные элементы зеркалятся
- **CSS-переменные** — все цвета сайта заданы в `:root` и используются через `var(--...)`
- **CSS-анимация** — «парящая» иконка Play на обложках YouTube-видео (`@keyframes playFloat`), а также аналогичная анимация для иконки Telegram в карточках участниц (`@keyframes tgFloat`)
- **Форма** (`contact.html`) — 4 типа полей: текстовое (имя), email, текстовое (Telegram), textarea (сообщение), чекбокс согласия и кнопка отправки
- **ООП на JavaScript** — класс `ContactRequest` с конструктором (сохраняет имя, email, telegram, сообщение, согласие и дату создания) и методом `print()` для форматированного вывода заявки в консоль. При отправке формы создаётся объект класса и вызывается `print()`
- **БЭМ** — все классы на страницах названы по методологии: блоки (`member-card`, `project-card`, `contact__form`), элементы (`member-card__image`, `contact__input`) и модификаторы (`btn--tiktok`, `btn--blocked`)
